# 判断の記録

課題に書かれていない部分をどう決めたか、なぜそう決めたかの記録。仕様そのものは [SPEC.md](SPEC.md)。

## 1. バージョンの選定（2026-09-03 に Docker Hub / Packagist / 公式ドキュメントで実測）

| 対象 | 採用 | 根拠 |
|---|---|---|
| PHP | 8.5.10（`php:8.5.10-fpm-alpine`） | Docker Hub 公式イメージの最新安定版 |
| MySQL | 26.7.0（Innovation、パッチまで固定） | `mysql:latest` = `innovation` = 26.7。MySQL 公式マニュアルの「Innovation 系列 = 26.7、LTS 系列 = 9.7」に基づき「最新リリース」を 26.7 と解釈。LTS 9.7.2 でも migrate・seed・テストが通ることを確認 |
| Laravel | 13.x（framework 13.30.1） | 最新のメジャー。PHP 8.3〜8.5 対応。公式 CI は MySQL 9.7 で実行 |
| Web サーバー | nginx | php-fpm と分離する一般的な構成 |

MySQL は Laravel 本体の CI が 9.7 LTS で回っているため 26.7 は動作保証外だが、Innovation の差分は追加機能中心で CRUD 用途では問題が出にくいと判断し、両方で確認したうえで 26.7 を採用した。

## 3. 途中で変えた判断

- **ログインを追加**（#21）: 第三者が勝手に日記を変更できないようにするため。ユーザー登録画面は作らず、持ち主 1 人をシーダーで作る。ログイン試行は 1 分 5 回まで。
- **一覧をトップページ `/` に**（#5）: サービスとしてトップ URL に中身がある形にするため。`/diaries` は 301 で `/` へ。
- **テーマを「開発者の 1 行日記」に**: サイト名は「ひとこと開発日誌」。データ構造と機能は課題どおりで、名前・例文・デザインだけを寄せた。
- **詳細ページを追加**（#32）: デザインに詳細ページがあり、画像を大きく見せる場として採用。前後の日記への導線とシェアも付けた。タグ・検索・月フィルタ・統計・状態バッジは課題に無いので置かない。
- **Tailwind CSS を CLI ビルドで**（#26）: 審査者に Node を要求しないため、出力 CSS をコミットする。Play CDN は本番向けでないので使わない。
- **画像の軽量化**（#37）: JPEG をそのまま配信せず、WebP / AVIF を保存時に生成。OGP は互換性のため JPEG。縦横 6000px 超は弾く（14000×14000 の JPEG でメモリ不足になることを確認したため）。
- **シーダーを開発の記録に**（#45）: 一覧を見るだけで作り方が伝わるように、日記の内容をこのサイトの開発記録にし、Gemini で生成した画像を同梱した。
- **ダミー画像**: 画像が無い日記はカードの形をそろえるためダミー画像を出す。

## 4. 開発中に起きた問題と対処

- **テストが開発用 DB に向いていた**（#4）: compose の環境変数 `DB_*` が phpunit.xml より優先され、シードデータが消えた。環境変数を外し、接続先が `_test` でなければテストを中止するガードを `tests/TestCase.php` に入れた。
- **CSS のコミット漏れ**（#9）: テンプレート更新前のビルド結果をコミットして CI の一致チェックに止められた。コミット前に必ず再ビルドと差分確認をする手順を `CLAUDE.md` に明文化した。
- **`robots.txt` が nginx 経由で 404**（#36）: 静的ファイル前提の location ブロックが残っていた。テストは nginx を通らないため気づけない種類の問題で、実環境の curl で発見した。
- **絶対 URL が Host ヘッダに依存**（#36）: 偽の Host で sitemap のキャッシュを汚染できたため、`URL::forceRootUrl(APP_URL)` で固定した。
- **PHP 8.5 の OPcache**（#1）: 組み込み済みのため `docker-php-ext-install opcache` はビルドが失敗する。
